# 三国：天下为注

纯前端离线网页游戏：加载后无后端，本地直接玩。

**史书只写了沙场，没写牌桌。** 你捡到一部残卷《英雄记》，记的是另一部三国——乱世英雄，白天争天下，夜里赌江山。每翻一页，乱世就重来一次；赢下牌局，就改写一段遗憾。集齐三十枚野史朱印，写卷人会在最后一页等你。


## 多平台壳（Android / Windows / Linux）

同一 web 构建产物 `dist/` 打三种壳，与 iOS/macOS 原生版并行：

- **Android**：`android/`（Capacitor）。`npm run build && npx cap sync android`，JDK 21 下 `./gradlew assembleDebug` 出 APK。
- **Windows / Linux / macOS(Electron)**：`desktop/`。tag `v*` 触发 `.github/workflows/desktop-release.yml` 三平台矩阵出包（NSIS exe / AppImage+deb / dmg）并附到 GitHub Release；注意 `productName` 必须为 ASCII（AppImage 路径安全），中文标题由 `main.js` 设置。
- **六语言**：web 与原生共用 `native/App/Resources/Localizations/*.json` 词表（`src/i18n.js` 运行时：首启随系统 → 设置持久化 → 非中文回退中文）。

## 原生单机版（iOS / macOS）

`native/` 目录内是 SwiftUI 原生移植：引擎与网页版**逐位一致**（黄金向量测试全过）、完整章节流程、野战练习场、观阵录、网页存档互通、六语言 i18n（中/日/韩/英/西/德）。详见 [native/README.md](native/README.md)。

## 运行

```bash
npm start
# 打开 http://127.0.0.1:8619/
```

`npm start` 会先写入 `runtime.json`，构建带内容哈希的 JS/CSS、按需章节包和 PWA Service Worker，再从 `dist/` 启动静态服务器。`npm run build` 可单独生成不含测试夹具的生产目录。页面右下角显示版本号、提交短 SHA 和本次服务器启动时间（UTC），便于判断当前打开的是哪次部署；旧服务若显示“启动时间未登记”，说明没有按新方式启动。`runtime.json` 与 `dist/` 已加入 `.gitignore`，不需要提交。

## 安装与离线

- Chrome／Edge 支持时，目录工具栏会出现“安装 App”；也可使用浏览器菜单的安装入口。
- iPhone／iPad 使用 Safari 的“分享 → 添加到主屏幕”。
- 首次联网打开后自动预缓存应用壳和全部章节；之后可从图标离线重开，未访问过的章节也能进入。
- 头像按需缓存，未缓存的离线图显示统一占位，不会错配其他武将。更新仍由用户点击刷新，不强制中断牌局。

## 存档备份

目录工具栏的“存档”支持导出带格式版本号的 JSON 文件，也支持导入本游戏备份。导入先显示改写页数、武将列传数、终局数、野战场次和导出时间，只有确认覆盖后才写入；无效文件不会修改当前进度。未结算的行军和牌局不包含在存档中。

## 玩法与剧情

- **残卷四卷五十回 + 最后一页**：每回都有独立冷开场、本回目标、故人名单、章节专属行军场景、牌局拍点、胜负双结局与下一页钩子。从桃园、岘山、界桥、神亭岭，到白马、南郡、潼关、葭萌关、单刀会、逍遥津，再到天水、陈仓、上方谷、淮南三叛、甘露殿、剑阁、羊陆之交，主线与魏蜀吴分支俱在。不是只换一句题记。
- **史实底稿与逐战战书**：每回标明公元纪年、史籍／演义来源与改编边界；普通遭遇、关底、多人、连战每一阵、长坂再战和随机外传，都在牌局前展开战书，写清对手、缘由、胜后所得与败后代价。
- **写卷人主干**：白门楼、华容、麦城、五丈原等选择会流进后页，改变人物对白、入场态度和剧情。胜利后可直接续读下一回；终章可封卷、还史或撕卷，撕卷通向无终稿。
- **128 名历史角色**：刘备、关羽、张飞、赵云、典韦、陈宫、貂蝉、孙权、鲁肃、庞统、黄忠、马谡、王平、姜维之外，孙坚、孙策、太史慈、甘宁、张辽、马超、许褚、庞德、颜良、文丑、徐晃、张郃、郝昭、邓艾、钟会、羊祜、陆抗、杜预、王濬等尽数入席。可靠本地《三国志9》编号头像逐一对照；少数无可靠独立头像的守将明确使用通用武将像，不错配他人。
- **故人真的记得你**：同一武将重逢时会读取此前胜负、选择和列传记录。白门楼影响煮酒，华容影响麦城与归晋，麦城影响夷陵、白帝城，空城与五丈原影响高平陵。
- **德州扑克即战斗**：单挑短局，也支持真正的同桌 1v2／1v3。每位敌将独立军资、手牌、人格、破绽、情绪和行动；支持按钮与盲注轮换、多人下注、主池／边池、平分、淘汰和筹码守恒。
- **野战练习场**：目录与正史并列的「野卷 · 沙场点兵」横幅入口，进入全屏点兵台，33 处三国典故牌桌按桌型七阵分档——单挑（温酒斩华雄、神亭酣战、煮酒论英雄、空城抚琴、华容狭路、五丈秋风、陈仓坚壁、天水麒麟）、鼎足（凤仪亭、水淹七军、潼关、白衣渡江、羊陆之交、甘露之变、阴平、濡须）、四战（三英同席、舌战群儒、官渡、逍遥津、白门楼、王濬楼船）、五虎（河北四庭柱、淮南三叛、铜雀夺袍、上方谷）、六合（千里五关、南中七纵、五子良将、五虎上将）、七星（西川夺蜀）、八荒（江东虎臣、讨董诸侯）。2 至 8 人桌，军资全员等额、盲注按深度配置，页头累计战绩与破阵数，胜负只记练习簿与列传，不动正卷。
- **可开关的局势分析**：页脚“设置”开启后，牌桌按你的手牌、公共牌和未弃牌对手数动态显示胜率、平分率、多人期望底池份额、听牌 outs 与河牌终局牌型概率。翻牌／转牌穷举剩余公共牌，胜率在 Web Worker 中独立模拟，不读取暗牌或未来牌序，也不影响发牌和 AI。
- **明确的全压与退回**：全压按钮显示全部剩余筹码，只在真正可全压下注时出现；行动后展示投入金额与剩余 0。超过对手跟注能力的部分按规则退回，并在结算中注明，不把退款误作未下注。
- **十几场同桌多人关**：凤仪亭、白门楼、长坂坡、舌战、赤壁、定军山、麦城之外，岘山（黄祖／蔡瑁）、白马延津连阵、潼关（马超／许褚）、濡须（曹操／徐晃）、逍遥津（张辽／乐进）、水淹七军（于禁／庞德）、上方谷（司马懿／司马昭）、淮南两叛（毌丘俭／文钦、诸葛诞／文鸯）、甘露殿（贾充／司马昭）、阴平（邓艾／邓忠）、归晋（司马炎／王濬）皆为同席对局。赤壁为曹操／周瑜／诸葛亮三方同桌；敌将之间也会彼此赢取军资，所有敌将离席才获胜。
- **named 连战**：千里走单骑依次迎战孔秀、韩福、卞喜、王植、秦琪；三顾前两顾即使失利也会继续，第三顾才揭示卧龙真正要考的是什么；白马对颜良、延津对文丑两阵连打；淮南三叛毌丘俭、文钦与诸葛诞、文鸯两叛连平；七擒孟获由孟获、孟优、祝融、带来洞主、兀突骨轮番上阵，每阵都有态度变化。战书返回后再入会续接当前阵，不重刷军资或剧情。
- **破绽**：每名对手有签名破绽，可能是假动作。席位直接显示当前动作，摊牌后破绽簿验证判断；列传记录见过几次、识破几次。
- **攻心／观星**：每手一次。多人局先点击席位选目标，再施放；只影响选中的武将。五丈原改写后解锁“执子之手”，攻心化为观星。
- **天时**：开卷三选一（粮草／夺气／看破／劫营），决定本回起手策略。
- **兵败也产内容**：失败会写回原卷，并留下本回“史鉴”：解释真正看错了什么，重开时提供新的机制提示或天时效果，不直接送胜。
- **大关机制**：白门楼困兽、长坂坡七进七出、麦城白衣全谎、五丈原秋风起等专属规则与开场演出。
- **残卷无终稿**：通关后开放随机外传页，只计胜场，不占正卷。
- **验牌**：每手牌由种子洗牌，战斗中可回放整副牌序。写卷人规矩一：牌可验。

## 开卷与界面

- **四短节开卷**：说明读卷人的身份、史籍与演义边界、胜负与史鉴、牌局目标、破绽／攻心／天时／行军；每次翻页都有淡出收拢与展开淡入，连点不会越过内容，减少动态效果时直接换文。可跳过，目录可重温。天时、地图、下注、破绽和攻心另有第一次真实操作时的情境提示。
- **史诗展卷**：战书以卷轴杆、纸面展开、朱印和本地立绘构成入场仪式；信息不会因加速而省略，“略过展卷”只结束装饰动画。移动端使用不裁文字的淡入，正文和按钮均避开两侧卷轴杆及底部安全区。支持键盘焦点、Escape 返回、减少动态效果与手机独立滚动。
- **章节专属入场**：战书确认后才进入武将卡。武将卡包含本地头像、章节小传、旧账台词、本回战法与真实六维；多人关逐将亮相，重复挑战不重复播放入场，新条件版本仍会出现。
- **席位化牌桌**：头像、姓名、军资、情绪、签名破绽和详情入口都归属于各武将席位。多人局当前行动者自动居中，窄屏可横向滑动；点击席位选择攻心／观星目标，点“谱”查看完整武将卡。
- **三国古风 UX**：开卷 → 史实底稿／冷开场 → 天时 → 行军见闻 → 战前展卷 → 武将亮相 → 对局 → 朱批结算／续读下一回。
- **观阵录**：同一套立绘与六维用于入场和列传，展示战绩、出场回目与识破记录；刷新后保留。
- **响应式与可访问性**：桌面与窄屏分别排布，章节正文独立滚动、底部操作区固定并适配手机安全区；移动端保留横排行动按钮，支持键盘节点、减少动态效果和演出加速。
- **弱网加载与按需剧情**：首屏加载状态独立于业务模块，慢网有提示、失败可手动重试；打开具体章回时才下载对应剧本与战书，章节资源失败也可重试。HTML 与 `runtime.json` 不缓存，内容哈希 JS/CSS 和头像长期缓存。
- **牌桌角色与弃牌可视化**：双方席位直接标明庄位、小盲、大盲及金额，并随每手轮换；多人弃牌立即收走该席位两张手牌，持续显示“已弃牌”，玩家弃牌后进入观战，下一手自动复位。
- **社交分享卡**：内置 1200×630 JPEG 大图，Open Graph 与 Twitter Card 共用绝对图片 URL、标题、描述和替代文本；图片按版本命名，避免改版后平台继续使用旧缓存。
- **部署版本页脚**：右下角展示版本号、提交短 SHA 与服务器启动时间（UTC），可手动强制刷新，也可进入／退出浏览器全屏；外部退出全屏后按钮状态会自动同步。

## 人格基座

对手的牌风由六维三国语义属性驱动（`src/persona.js`）：**武勇**（进攻／价值打薄）、**智谋**（读人／连环／借题）、**诈术**（诈唬／半诈唬／假破绽）、**胆识**（抗压）、**耐性**（慢打／跟注火候）、**心性**（情绪稳定／激将相性）。每个维度都真实改变牌局。

胜率判断与人格分离：单挑翻牌前查 169 类离线胜率表，其余局面做可复现蒙特卡洛模拟，并显式传入当前存活对手数。接近底池赔率边界时提高精度；多人平分按实际并列人数计算底池份额。

## 内容即数据

- `src/chapters.js`：年号、地名、规则、阵容与天时。
- `src/story-data/scroll-*.js`：四卷与终章完整剧本。
- `src/story-data/briefings.js`：33 回史实底稿、改编说明、逐战战书与连战分阵文本。
- `src/story-engine.js`：条件、场景、入场、拍点和结局解析。
- `src/generals.js` / `src/portrait.js`：武将档案、台词、签名破绽与头像映射。
- `src/encounters.js`：单对手、同桌阵容与 named 连战归一化。

配方由 `tests/content/chapters.lint.mjs` 把守：全部 33 回必须有完整剧本、史实底稿和两类战书，连战必须逐阵覆盖；人物和场景引用必须有效，多人阵容为 2–3 名对手，连战配置与轮次一致。

## 设计笔记

第一版是 3D（Three.js），教训：小团队做“精致 3D”性价比极低，人物模型的廉价感会毁掉氛围。2D/2.5D 把“精致”转移到字体排印、平面插画、人物文本和 CSS 动效上——暮色当铺的案底在 `archive-3d/`。

头像原作者及版权归属光荣特库摩；公开或商用发布前需按素材目录说明另行确认授权。
